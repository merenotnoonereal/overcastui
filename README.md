# OvercastUI

> An in-game web browser for Minecraft. Browse the web, read a wiki, or watch video in picture-in-picture — without alt-tabbing or pausing your game. Steam-overlay-style, client-side Fabric mod.

[![CurseForge](https://img.shields.io/badge/CurseForge-download-orange?logo=curseforge)](https://www.curseforge.com/minecraft/mc-mods/overcastui)
![Loader](https://img.shields.io/badge/loader-Fabric-blue)
![Side](https://img.shields.io/badge/side-client--only-brightgreen)

OvercastUI is a **client-side Fabric mod** that puts a full Chromium web browser inside Minecraft as a **Steam-overlay-style** overlay. Summon it with a hotkey (default **Shift+Tab**) to browse the web, read a wiki, or keep a video playing in picture-in-picture — all **without alt-tabbing and without ever pausing your game**.

## Features
- **Full web browser in-game** — back/forward/reload, address bar, find-in-page.
- **Multiple draggable, resizable windows** with **tab support**.
- **Picture-in-Picture** — keep a video playing in the corner while you play.
- **Split-view** — read two pages side by side.
- **Customizable theme** — adjust opacity and backdrop.
- **Rebindable hotkey** — default Shift+Tab.
- **Tab suspension** — idle tabs are suspended to save resources.
- **Never pauses your game.**

## Great for
- Reading the **Hypixel Skyblock wiki** (or any wiki) without leaving the game
- **Watching a video / stream** in picture-in-picture while you grind
- Quick lookups, guides, and reference — mid-game, no interruption

## Installation
1. Install [Fabric Loader](https://fabricmc.net/use/) and [Fabric API](https://modrinth.com/mod/fabric-api).
2. Download OvercastUI from [CurseForge](https://www.curseforge.com/minecraft/mc-mods/overcastui).
3. Drop the `.jar` into your `mods` folder and launch. Press **Shift+Tab** in-game to open.

## FAQ
- **Does it pause my game?** No — your game keeps running underneath.
- **Can I watch video / YouTube while playing?** Yes — Picture-in-Picture.
- **How do I open it?** Default hotkey is Shift+Tab (rebindable).
- **Is it client-side?** Yes.
- **Can I move and resize the windows?** Yes, and you can have multiple with tabs.
